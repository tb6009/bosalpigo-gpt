# 15. v1.6 GPT 시스템 프롬프트 / 구현 명세

> 작성: 2026-05-16  
> 대상: `outputs/보고살피다_GPT/index.html`  
> 성격: v1.6 평가 결과를 반영한 GPT API 버전 보완판  
> 핵심: 프롬프트 의존도를 줄이고, 위험·프로브·SNS 노출을 코드에서 먼저 제어

---

## 1. v1.6 목표

v1.6은 원본 `10-일상다반사`의 v1.6 방향을 GPT 버전에 맞게 이식하되, 다음 약점을 보완한다.

1. 동의 게이트가 프롬프트 지시에만 의존하던 문제
2. 프로브 진행/중단/임계치가 상태로 관리되지 않던 문제
3. 위기·트라우마·섭식 위험 상황에서 SNS 인사가 섞일 수 있던 문제
4. GPT 버전에서 v1.6 정책이 별도 탭으로 분리되지 않았던 문제

---

## 2. 사용자 노출 버전

`outputs/보고살피다_GPT/index.html`에 다음 탭을 추가한다.

- **v1.6**

기본 진입 버전은 `v1.6`이다.

## 3. v1.6 핵심 정책

### 3.1 챗봇 역할

- 진단자 X
- 평가자 X
- 동반자·안내자·연결자 O

### 3.2 대화 기본 흐름

1. 평범한 인사
2. 가벼운 몸 상태 확인
3. 편안한 대화
4. 필요할 때만 동의 요청
5. 동의 후 자연어 프로브
6. 임계치 충족 시 정식 도구/전문가 안내

---

## 4. 코드 제어 항목

v1.6에서는 아래 항목을 모델에게만 맡기지 않고 브라우저 코드가 먼저 처리한다.

### 4.1 위기어

자살·자해 키워드는 API 호출 전에 차단한다.

동작:

1. 위기 모달 표시
2. 고정 안전 응답 출력
3. 대화 기록 저장
4. API 호출하지 않음

안내 번호:

- 자살예방상담전화 109
- 정신건강위기상담전화 1577-0199
- 응급 시 112 / 119

### 4.2 자연어 프로브 상태

`localStorage` 키:

```js
bosalpigo.gpt.probe
```

상태 예:

```js
{
  type: "sleep",
  awaitingConsent: true
}
```

또는:

```js
{
  type: "sleep",
  active: true,
  index: 2,
  yes: 1,
  answers: []
}
```

### 4.3 SNS 인사

`v1.6`에서만 하루 1회 사용한다.

단, 다음 상황에서는 코드상 진입하지 않는다.

- 위기어 감지
- 프로브 동의 대기
- 프로브 진행 중
- 수면/스트레스/섭식/트라우마 트리거 직후

---

## 5. 프로브 대상

| type | 영역 | 도구 | 담당 | 임계치 |
|---|---|---|---|---|
| `sleep` | 수면 | PSQI | 모미 | yes 3개 또는 수면제 문항 yes |
| `stress` | 스트레스 | PSS | 마음 | yes 3개 |
| `eating` | 섭식 | EAT-26 | 모미·숨이 | yes 2개 또는 구토/굶기 문항 yes |
| `trauma` | 트라우마 | PC-PTSD-5 | 숨이 | yes 2개 |

주의:

- 프로브는 정식 척도 문항이 아니라 자연어 징후 질문이다.
- 점수 계산이나 진단 라벨은 제공하지 않는다.
- 임계치 충족 시 정식 도구명과 전문가 연결을 안내한다.

---

## 6. v1.6 시스템 프롬프트 요지

앱 내부 `buildPrompt("1.6", profile)`은 다음 원칙을 포함한다.

```text
너는 보살피고 GPT v1.6이다.
진단자가 아니라 동반자·안내자·연결자다.
앱 코드가 위기·프로브·SNS 노출을 먼저 제어한다.
코드가 동의 요청이나 프로브를 처리한 경우 그 흐름을 뒤집지 않는다.
SNS 인사는 안전한 일반 대화에서만 사용한다.
위기·트라우마·섭식 위험에서는 SNS 인사를 사용하지 않는다.
```
